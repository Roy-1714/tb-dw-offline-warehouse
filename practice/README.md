> 全部在你自己的 tb_dw 库上做，数据是真的（9 天、1 亿行）。

## 怎么用

```bash
# 1) 复制模板
cp practice/q_template.sql practice/q1.sql

# 2) 写完后执行（走同一个 Spark SQL 环境，YARN 上跑）
bash practice/run_sql.sh practice/q1.sql

# 3) 把 SQL + 结果贴给我，我按三条标准批改
```

**批改标准**（每条都会明确指出来）：
1. 能不能跑通（语法、字段名、分区过滤）
2. 口径对不对（分母是谁、去重还是计数、跨天怎么处理）
3. 有没有更优写法（窗口写法、join 是否放大、是否扫了不必要的分区）

## Q1 日粒度行为分布（基础聚合）

**表**：`dwd_user_behavior_detail`（`user_id, item_id, category_id, behavior_type, ts, event_time, hour, is_weekend, dt`）

**要求**：对 `dt='2017-12-02'`，输出每种 `behavior_type` 的
- 行为次数（行数）
- 去重用户数

按行为次数降序。

**考点**：`count(*)` 与 `count(distinct user_id)` 的区别；只扫一个分区。

---

## Q2 每日浏览→购买转化率（口径）

**表**：`dws_user_action_1d`（`user_id, pv_cnt, cart_cnt, fav_cnt, buy_cnt, dt`）

**要求**：9 天逐日输出
- `pv_uv`：当日有浏览的用户数
- `buy_uv`：当日有购买的用户数
- `pv2buy_rate`：`buy_uv / pv_uv`，保留 4 位小数

按日期升序。

**考点**：条件是"次数 > 0"而不是"有记录"；分母口径要写死。

---

## Q3 每个用户浏览最多的前 3 个商品（分组 TopN）

**表**：`dwd_user_behavior_detail`

**要求**：`dt='2017-12-02'`，对每个 `user_id`，取他当日 `behavior_type='pv'` 次数最多的前 3 个 `item_id`，输出
`user_id, item_id, pv_cnt, rk`。

**考点**：先按 `(user_id, item_id)` 聚合，再用窗口排名；直接在明细上 `row_number` 是错的（会把重复浏览当成不同商品）。

---

## Q4 每日新客占比（跨层 join）

**表**：`dws_user_action_1d`、`dws_user_action_td`（后者含 `user_id, first_dt, last_dt, dt`）

**要求**：逐日输出
- 活跃用户数
- 新客数（当日首访：`first_dt = 当日`）
- 新客占比（4 位小数）

**考点**：join 必须带 `dt` 条件，否则 td 有 9 个快照会把人数放大 9 倍——这是最常见的"静默错误"。

---

## Q5 新增用户留存（基准集）

**表**：`dws_user_action_td`、`dws_user_action_1d`

**要求**：以 `first_dt='2017-11-25'` 的用户为基准（这批人就是 11-25 的新增），计算他们在
`2017-11-26`、`2017-11-28`、`2017-12-02` 三天仍活跃的人数和留存率（4 位小数）。

**考点**：分母是**基准人数**；基准集要和活跃表左连接，不要反过来。

---

## Q6 加购→购买的两种转化（口径歧义）

**表**：`dws_user_action_1d`

**要求**：对 `dt='2017-12-02'` 输出三个数
- `cart_uv`：当日有加购的用户数
- `buy_uv`：当日有购买的用户数
- `cart_and_buy_uv`：当日**既加购又购买**的用户数

然后给出两种转化率并说明差别：
- 漏斗型：`buy_uv / cart_uv`
- 同人型：`cart_and_buy_uv / cart_uv`

**考点**：能讲清"漏斗转化"和"同人转化"不是一回事，面试官很爱问。

---

## Q7 Top10 商品 + 倾斜判断（优化）

**表**：`dws_item_action_1d`（`item_id, pv_cnt, uv_cnt, buy_cnt, dt`）、`dwd_user_behavior_detail`

**要求**：
1. 取 `dt='2017-12-02'` 按 `pv_cnt` 前 10 的商品（`item_id, pv_cnt`）
2. 算出这 10 个商品占当日总浏览量的比例
3. 文字回答：如果把这张 Top 表按 `item_id` 与明细表 join，会不会倾斜？为什么？
4. 文字回答：给出一种改写方案（加盐 / 广播小表 / 两阶段聚合，任选并说明适用条件）

**考点**：拿数据说话，而不是背"数据倾斜就用加盐"。

---

## Q8 日环比与累计增幅（窗口函数）

**表**：`dws_user_action_1d` 或 `ads_dau_1d`

**要求**：逐日输出
- 当日 `pv`
- 前一日 `pv`（`lag`）
- 日环比（%，2 位小数，首日为 NULL）
- 相对 2017-11-25 的累计增幅（%，2 位小数）

**考点**：`lag` 窗口 + 首日为 NULL 的处理；累计增幅的基准要用固定日。
