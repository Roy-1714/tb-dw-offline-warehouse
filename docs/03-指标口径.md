# 03 指标口径

> 原则：**只写数据能支撑的指标**。本数据集无金额字段，因此不做 GMV/客单价/退款率/ROI，也不做"用购买次数冒充金额"这类假指标。
> 每条口径都能追溯到具体表与字段。

## 通用定义

| 名称 | 定义 |
|---|---|
| 活跃用户（UV） | 当日 `dwd_user_behavior_detail` 中出现的去重 `user_id` 数 |
| 浏览量（PV） | 当日 `behavior_type='pv'` 的行数 |
| 新增用户 | `dws_user_action_td` 中 `first_dt = 当日` 的用户 |
| 老用户 | `first_dt < 当日` 的活跃用户 |
| 业务日 | 北京时间自然日，由 `ts`（UTC 秒）换算 |

## 1. ads_dau_1d 日活核心

| 指标 | 口径 |
|---|---|
| pv | `sum(pv_cnt)`，来自 `dws_user_action_1d` |
| uv | `count(1)`（1d 表一用户一行） |
| buy_uv | `count(if(buy_cnt>0))` |
| pv_per_uv | `pv / uv`，保留 4 位 |
| new_uv / old_uv | 与当日 `dws_user_action_td` 快照 join，比较 `first_dt` |
| is_weekend | 来自 `dim_date` |

## 2. ads_funnel_1d 行为漏斗

漏斗口径是**去重人数**，不是次数：

| 指标 | 口径 |
|---|---|
| pv_uv | 当日有 pv 的用户数 |
| cart_uv | 当日有 cart 的用户数 |
| fav_uv | 当日有 fav 的用户数 |
| buy_uv | 当日有 buy 的用户数 |
| pv2cart_rate | `cart_uv / pv_uv` |
| cart2buy_rate | `buy_uv / cart_uv` |
| pv2buy_rate | `buy_uv / pv_uv`（整体转化） |
| pv2fav_rate | `fav_uv / pv_uv` |

**注意**：这是"当日同天漏斗"，不跟踪跨天转化（跨天需要行为序列归因，本数据集可做但不在当前口径内）。

## 3. ads_retention_1d 留存

| 指标 | 口径 |
|---|---|
| new_uv | 首访日 = dt 的用户数 |
| d1_uv | 其中在 `dt+1` 仍有行为的用户数 |
| d1_rate | `d1_uv / new_uv` |
| d3_uv / d3_rate | `dt+3` |
| d7_uv / d7_rate | `dt+7` |

**边界说明**：数据只有 9 天，`dt+7` 对 11-27 之后的日期不可得，对应 `d7_*` 为空或偏小，属数据窗口限制，不是计算错误。这条必须在报表上标注，否则会被当成留存骤降。

## 4. ads_hour_active_1d 分时活跃

| 指标 | 口径 |
|---|---|
| hour | 0-23（北京时） |
| pv | 该小时 pv 行数 |
| uv | 该小时去重用户数 |

## 5. ads_item_topn_1d 商品 TopN

| 指标 | 口径 |
|---|---|
| rk | 当日按 `pv_cnt` 降序排名，取前 50 |
| pv / uv / buy_uv | 来源 `dws_item_action_1d` |

## 6. ads_category_topn_1d 类目 TopN

同商品 TopN，按 `category_id` 聚合，取前 30。

## 7. ads_buy_freq_dist_1d 购买频次分布

| 指标 | 口径 |
|---|---|
| freq_bucket | 当日购买次数分档：1 次 / 2 次 / 3-5 次 / 6 次及以上 |
| user_cnt | 落在该档的用户数（仅统计 `buy_cnt>0`） |
| ratio | 该档 / 当日购买用户总数 |

## 8. ads_user_rf_seg_1d RF 分层

**不做 RFM**：M（金额）维度本数据集无法获得，强行用购买次数替代会误导。

| 维度 | 分档 |
|---|---|
| R（最近活跃近度） | `datediff(当日, last_dt) <= 1` → R1_近；`<=3` → R2_中；否则 R3_远 |
| F（累计购买频次） | `buy_all >= 5` → F1_高频；`>=1` → F2_中频；否则 F3_未购买 |
| segment | `R*_* + "-" + F*_*` |

指标：`user_cnt`、`ratio`、`avg_recency_day`、`avg_buy_cnt`。

## 9. ads_path_analysis_1d 行为路径

| 指标 | 口径 |
|---|---|
| path | 用户当日按 `ts` 升序的前 4 个行为，用 `->` 连接（如 `pv->pv->cart->buy`） |
| user_cnt | 走该路径的用户数 |
| ratio | 该路径用户 / 当日有行为用户 |
| rk | 按用户数降序，取前 20 |

**口径限制**：只取前 4 步，且未做 session 切分（数据无 session_id），因此是"当日行为序列"而非严格会话路径。这个限制要在文档里写明。

## 10. ads_item_skew_1d 商品访问集中度

这张表的用途是**给数据倾斜治理提供量化依据**，不是业务报表。

| 指标 | 口径 |
|---|---|
| item_cnt | 当日有行为的商品数 |
| pv_total | 当日总浏览量 |
| top1pct_item_cnt | `percent_rank() >= 0.99` 的商品数（约前 1%） |
| top1pct_pv | 这些商品的浏览量 |
| top1pct_share | `top1pct_pv / pv_total` |
| max_item_share | 单商品最大浏览量 / `pv_total` |

用法：若 `top1pct_share` 极高（例如 >50%），说明按 `item_id` 做 join/聚合必然倾斜，需要两阶段聚合（加盐）或 MapJoin 广播小表；该表给出的就是"要不要加盐、盐要加多少"的依据。

## 指标与简历的对应关系

- 能讲：UV/PV、漏斗转化率、次日与 7 日留存、复购频次分布、RF 分层、路径 TopN、商品集中度
- 不能讲：GMV、客单价、退款率（本数据集无金额/订单状态字段）
